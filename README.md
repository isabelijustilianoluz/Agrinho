# 🧠 Inteligência Artificial: Mapeando Ideias e Prototipando Soluções

Site educacional e institucional sobre como a IA pode ser utilizada para **mapear ideias** e **prototipar soluções** de forma estratégica.

## 🚀 Deploy
Este site está pronto para ser publicado no **GitHub Pages**:
1. Crie um repositório público
2. Faça o upload dos arquivos `index.html`, `style.css` e `script.js`
3. Vá em **Settings → Pages → Source: main branch**
4. Acesse: `https://<seu-usuario>.github.io/<repositorio>/`

## 🎨 Tecnologias
- HTML5 semântico
- CSS3 (variáveis, grid, flexbox, animações)
- JavaScript vanilla (interatividade e scroll)

## 📌 Seções
- Hero / Apresentação
- O que é IA
- Mapeamento de Ideias
- Prototipagem de Soluções
- Fluxo IA (Ideia → Mapeamento → Protótipo → Solução)
- Ferramentas de IA
